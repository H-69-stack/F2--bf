## 推送踩坑（重要，下次备份直接用）
- **症状**: 默认 HTTP/2 下 `git push` 连上（443 established）但**零字节传输**，挂 2 分钟无任何输出。
- **根因**: 本机 git 走 schannel + 自签 CA（`C:\ProgramData\scholartools\certs\scholar.crt`），HTTP/2 复用下上传会卡住。
- **解法**: 仓库级配置改用 HTTP/1.1
  ```
  git config http.version HTTP/1.1
  git config http.postBuffer 52428800
  git config http.lowSpeedLimit 1000
  git config http.lowSpeedTime 60
  ```
  改完 **9.89 MiB/s、4 秒传完**（1.89 MiB pack）。
- 凭据已由 GCM 存于 Windows 凭据管理器（`git:https://github.com`，用户 `H-69-stack`），无需每次登录。
